DeepSeek 选择器 RSI：四种子等权历史回放
=====================================

数据：seed1、seed2、seed4、seed5；seed4 有两次记录，先对这两次求平均，
再让四个 seed 等权。没有 seed3。不把重复回放当作新增对局。

候选 v00–v11 就是当前 A00–A11 的别名，候选实现未修改。
没有训练或使用其他可学习的选择模型，也没有启用在线七技能或新仿真。
选择器只收到公开目标、己方库存、部署区域及计划的聚合特征；没有地图
编号、seed 编号、人工难度标签、隐藏目标和原始绝对坐标。

实际过程：
1. 20 个真实选择，18/20 命中历史均分最高候选，回放均分 93.0507411067。
2. DeepSeek 根据真实选择的历史回报修订经验，再做 20 个真实选择，
   20/20 命中，均分 93.1528491436。
3. 人工复核发现一条经验数字比较写反；让 DeepSeek 改成引用经验条目，
   程序验证支持/反例引用并从原始统计表填入事实数值。用这份修正版经验
   再做 20 个真实选择，仍为 20/20，均分 93.1528491436。

最终选项来自第 3 轮原始 API 回复，没有用程序事后替换动作。
程序做统计、证据校验和回放记分；实际选项仍由 DeepSeek 返回。
三轮总计 60 个选择、2 次经验修订，合计 14 次 API 请求。
累计输入 283864 tokens，输出 25254 tokens，含缓存命中 146560 输入 tokens。
按 API 用量及当日空闲费率计算费用 0.2412512 元；非账户账单。
累计费用低于本次 4 元上限。

产物：

experience/v00.txt 至 v11.txt：数值事实与假设分开的最终经验文档。
