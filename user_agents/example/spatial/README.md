# 空间波次与搜索恢复示例

两个入口分别导出无参 `Deployment` 和两参数 `RedAttack(entity_id, init_observation)`：

| 入口文件 | 方案 | 昨日录像组合 |
|---|---|---|
| `user_agents/example/coordination/r7_v3_0_spatial_packages.py` | R7 3.0：`baseline`，原R7+空间波次 | M01–B9，种子42 |
| `user_agents/example/coordination/r7_v4_0_search_recovery.py` | R7 4.0：`recovery`，搜索覆盖与任务恢复 | E06–B8，种子42 |

`recovery` 使用约半数清道夫分带搜索，在通信群内按距离分配已发现的暗巢，保存认领到期步号并在通信群重组时延续本机持有的任务。两个方案共享空间波次、任务延续和短时避让代码，包含不同的部署和作战规则。

## 运行

安装工程根目录 `requirements.txt` 中的依赖，使用 Python 3.11。根目录执行：

```powershell
python main.py --config reference_strategies/r7_video_20261104/M01_B9.yaml
python main.py --config reference_strategies/r7_video_20261104/E06_B8.yaml
```

示例配置使用正式 `Simulator`、完整 `TrainingEnv` 和原有计分。详细日志关闭，结果写入独立目录。需要录像日志时在配置中开启 `logging.enabled`，保留 `events` 和 `actions`。

## 代码职责

- `spatial_waves.py`：从受控单位、公开目标和公开区域生成初始位置、任务及预计到达步号。
- `strategies.py`：搜索部署、暗巢分配与认领到期释放。
- `spatial_commander.py`、`strike_coordination.py`、`task_memory.py`：本群任务、主攻损失后的补充分配及任务延续。
- `coordination.py`：按真实通信成员接收本机报告，群重组时传递本机任务；准备完成后释放原始报告。
- `short_evasion.py`：依据本机实际接收的自爆虫记录执行短时避让。
- `runtime.py`：公开接口、部署计划交接和按 `run_id` 隔离的作战资源。
- `public_geometry.json`、`geometry.py`：随附20张地图的公开部署区域、地图边界及步长，不含任何实体目录或暗巢数据。

部署观测未提供地图边界和步长，因此部署阶段按公开区域查表。几何表不支持的地图会明确报错，新增地图须同步登记公开几何数据。作战实例会核对种子、公开目标、地图边界、本机类型，并确认实际初始位置为有限数值且位于合法部署区域；引擎回传位置可能与提交位置略有不同，作战使用实际位置。搜索三机组在部署区域两侧预留100米，避免成员被压到同一边界点。部署和作战必须选择同一入口文件。正常流程依次执行部署、关闭部署对象、注册本局作战实例，再开始逐步决策。

位置与航点使用二维米制坐标，动作使用1/2/3，时间条件按整数步号处理。随附地图每步1000毫秒，原策略的预计速度、30步掩护提前量及45步认领延长量保留。作战信息仅来自公开初值及本机合法接收记录。

运行中收到的虫巢位置可能略超出地图范围。四个R7入口在发送动作时，将航点投影到公开地图矩形内的最近点，并将任务记忆中的已发送航点同步更新；原始目标记录、目标编号和发现条件保持不变。非有限坐标仍明确报错，地图内的航点不变。

原始源码和历史录像分数保存在 `reference_strategies/r7_video_20261104` 的说明中。当前工程的地图几何、引擎及接口已有更新，当前完整对局结果须单独测试；适配不承诺重现历史录像的分数或事件序列。

空间波次和损失补充分配按当前公开基础伤害估计：毁灭者对母巢、哨卫巢为15，突击者为5；目标血量优先读取公开目录。天眼计划按80步窗口选择一次使用时机。场景提供的多次额度尚未用于连续天眼计划。这些数值用于任务预算，实际伤害和增伤由引擎结算。

## 验证

```powershell
python -m unittest discover -s tests -p test_video_strategies.py -v
```

测试核对20张真实地图的公开几何数据，并对两组录像组合分别执行合法部署、关闭部署对象、注册策略和20步真实仿真，检查任务信息范围和资源释放。
