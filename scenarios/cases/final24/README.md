# 最终24张竞赛地图

## 统一规则

- 不新增实体类型；简单/中等/困难分别以 E01/M01/H01 为模板，按难度复制既有类型的计分实体，红方发射场位置一致。
- 雷达距离不在地图配置，统一由核心使用 200 km。
- 中性能弹 = 高性能弹×1.4；低性能弹 = (高+中)×1.5；蓝方拦截弹 = 低性能弹×1.5。
- 同类蓝方实体跨难度统一血量：目标16、阵地12、无人艇0.8。基准命中率下分别对应1枚高性能弹（或4枚中性能弹）、1枚高性能弹（或4枚中性能弹）、1枚低性能弹。
- 难度通过计分实体数、空间拓扑和弹药规模形成；12.84%由实体数量得到，不再通过放大单体血量实现。
